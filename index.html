Before we start

Cautionary note

  • Most of the tools are not provided and/or “officially supported” by the EUI
  • Tools have been verified by me, but I am also learning along the way with you

Full disclosure

My search for tools has been complemented with an AI-based query with the following prompt:

“Act as a data expert supporting researchers at an academic institution. List research- and academic-oriented tools and platforms that can help store, manage, and query data of the following types: image collection, large CSVs, oral history and text corpora. The audience is historians who are approaching the use of digital tools in their research workflow, so do not assume expert technical expertise”

EUI tools

The EUI ICT Service provides GDPR-compliant storage solutions:

  • Microsoft OneDrive for Business
  • Microsoft SharePoint
  • Network areas storage and shared folders (being phased out)

However: no structured DB platform is available on premise or as a provided cloud service

Tip

We strongly advise to adopt more than one solution at the same time, following 3-2-1 backup rule

Cases for OneDrive (and SharePoint)

General purpose cloud storage solution, valid for all files and GDPR compliant.

  • Common case: fully sync and backup from your computer
    • Caveat: what is deleted locally is deleted remotely (when connected)*
  • For extra security: DO NOT sync, still backup (via web app)
    • Keep a fully independent backup
    • Use it in unsecure research contexts

Tip

We strongly advise to use the EUI VPN when moving files over the Internet VPN Remote Connection access service

*OneDrive still keeps deleted files in the cloud “bin” for 30 days.

Image collections

Scans, photographs of archival documents, visual sources

Store and describe

  • Tropy: organise and tag archive photos on your desktop. Best first tool.

For publishing on the web

The following are Open Source tools to be deployed on a server, so they require web hosting and a certain level of technical competences:

  • Omeka S / Omeka Classic: describe and publish collections online
  • Recogito: image annotation.
  • IIIF viewers: Mirador, Universal Viewer

Bonus: transcribe and extract text

  • Transkribus: handwritten and printed text recognition, trainable on historical scripts (Free tier, with subscription)
  • eScriptorium: Open Source alternative, can be deployed or you can join a community server. Developed by the Digital Humanities group at the École Pratique des Hautes Études (EPHE) and the ALMAnaCH at INRIA
  • Tesseract via OCRmyPDF: OCR for printed text

CSV files

When Excel slows down or hits its limit (or just because text-based files are leaner to work with)

Explore and clean (no coding)

  • OpenRefine: fix spelling variants, standardise dates, reconcile names and places

Query like a database

  • Heurist (@Huma-Num): Hosted service, open to researchers
  • DuckDB: very large CSVs on a normal laptop. Requires deployment

Analyse with code (when ready): Jupyter Notebooks, R / RStudio, Google Colab

Visualise: Tableau, RAWGraphs (free tier, then subscription)

Start here

Start with OpenRefine, then anything else.

Oral history and interviews

Recorded interviews: audio, video, transcripts and the consent that goes with them

Record and edit audio

  • Audacity: free audio editor to trim, clean and convert recordings

Store - OneDrive / External hard drives

Analyse (code themes in interviews) MAXQDA: available via ICT

Transcribe

  • aTrain: tool for automatically transcribing speech recordings utilizing machine learning models without uploading any data. Developed by the Know-Center Graz.
  • noScribe: free automatic transcription that runs on your own computer (based on Whisper), so recordings never leave your machine

Check before you upload

Always consider the sensitive and personal nature of interviews and comply with GDPR and data security best practices.

Cross-cutting tools

Useful whatever your data type

Track versions

  • GitHub / GitLab: version control for code and small data files

Deposit and cite your data

  • Cadmus: the EUI Research Repository, also hosting orginal datasets produced at the EUI
  • But also: Zenodo, OSF, Harvard Dataverse

Anonymisation and Pseudonimisation

  • Amnesia (by OpenAIRE)
  • TextWash (python code available on GithHub)

Encryption

  • VeraCrypt
  • Cryptomator

Laerning opportunities

  • The Programming Historian
  • Library Carpentry, Data Carpentry, Software Carpentry: short hands-on workshops
  • Many more you may be aware of!!
